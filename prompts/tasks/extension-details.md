# Extension Details View

## Task Description
Implement the extension detail experience for marketplace extensions with a polished desktop UX.

## Requirements
- Extension detail page/view
- Detail layout structure
- Extension header section
- Extension overview section
- Metadata section
- Capability display section
- Compatibility display section
- Version/history preparation section
- Permissions/capabilities presentation UI
- Publisher/author presentation
- Installed status display
- Update available display
- Extension icon/banner placeholder support
- Loading state
- Empty/error states

## Implementation Details
- Use existing marketplace layouts/navigation
- Use existing extension card metadata patterns where appropriate
- Use existing shared UI primitives
- Maintain type safety
- Avoid duplicated display logic
- Responsive layout behavior
- Accessible UI structure
- Scalable page organization

## Expected Features
- Extension name
- Description
- Publisher/author
- Version
- Compatibility information
- Capabilities/permissions
- Category
- Tags
- Installed state
- Update state
- Extension status indicators
